# DocScreen — AI Identity Document Screening

An intelligent web application designed to streamline and automate identity document verification, tampering detection, and data extraction.

🔗 **Live Demo:** [https://docscreen-ai-identit-15ua.bolt.host](https://docscreen-ai-identit-15ua.bolt.host)

---

## 📌 Project Overview
Manual identity verification is slow and prone to human error. **DocScreen** provides a clean, fast dashboard where organizations can upload identity documents (such as Passports, National IDs, and Driver's Licenses) to automatically extract key fields, validate expiry dates, and flag potential tampering.

## ✨ Key Features
* **Secure Authentication:** Clean login portal with instant demo access for quick testing.
* **Interactive Document Screening:** Drag-and-drop upload interface supporting multiple ID document formats.
* **Multi-Step Verification Pipeline:** Simulates OCR text extraction, security watermark checks, font consistency analysis, and expiry validation.
* **Confidence Scoring & Reports:** Generates clear "Verified" or "Flagged" statuses with detailed field breakdowns.
* **Screening History:** Searchable and filterable audit log of previously screened documents.

## 🛠️ Tech Stack
* **Frontend:** React, TypeScript, Tailwind CSS
* **Icons & UI:** Lucide React
* **Deployment:** Bolt Hosting

## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project folder and install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
